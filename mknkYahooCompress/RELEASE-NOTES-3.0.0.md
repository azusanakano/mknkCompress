# mknkYahooCompress 3.0.0 Native

初回公開版です。

## 主な機能

- Yahoo!オークション向けJPG固定出力
- 1枚5,000,000 bytes以下
- 長辺1200px以下
- 容量内で知覚品質が最も高い候補を自動選択
- 画像・フォルダーのドラッグ＆ドロップと自動処理
- 完全オフラインのWin32ネイティブアプリ
- x64・x86・ARM64対応

## 配布物

- `mknkYahooCompress-3.0.0-Native-Windows-x64.zip`：一般的な64bit Windows PC向け
- `mknkYahooCompress-3.0.0-Native-Windows-x86.zip`：32bit Windows向け
- `mknkYahooCompress-3.0.0-Native-Windows-ARM64.zip`：ARM64 Windows向け
- `mknkYahooCompress-3.0.0-Native-Windows-All-Architectures.zip`：全CPU版
- `mknkYahooCompress-3.0.0-native-source.zip`：ソースコード
- `mknkYahooCompress-3.0.0-Native-SHA256SUMS.txt`：整合性確認用

## 確認事項

Windows実行ファイルはLLVM-MinGWでビルド済みです。ZIP展開検査、SHA-256照合、静的検査、参照アルゴリズム検査に合格しています。Windows実機での最終起動確認は別途行ってください。
