# Security Policy

## Supported version

| Version | Supported |
| --- | --- |
| 3.0.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

公開前に修正が必要な脆弱性は、公開Issueへ詳細を書かず、GitHubのPrivate vulnerability reportingが利用可能な場合はそちらを使用してください。

本アプリは画像と利用情報を外部送信しない完全オフライン設計です。実行時に予期しない通信、任意コード実行、パストラバーサル、元画像の破損などが確認された場合は、OS、アーキテクチャ、入力形式、再現手順を添えて報告してください。
