mknkYahooCompress 3.0.0 Native
================================

ヤフオク出品画像専用のWindowsネイティブJPG圧縮アプリです。
インストール不要・完全オフラインで動作します。

使い方
------
1. mknkYahooCompress.exe を起動します。
2. 画像またはフォルダーを画面へドロップします。
3. 元画像と同じ場所へ「元名_yahoo.jpg」が自動作成されます。

固定仕様
--------
- JPG固定
- 1枚5,000,000 bytes以下
- 長辺1200px以下
- 容量内で知覚品質が最も高い候補を採用
- 元画像は上書きしない

対応OS
------
Windows 10 / 11

プライバシー
------------
- 画像や利用情報を外部送信しません。
- 撮影情報・ICC保持は既定でOFFです。
- 設定は %LOCALAPPDATA%\\mknkYahooCompress\\settings.ini に保存します。
