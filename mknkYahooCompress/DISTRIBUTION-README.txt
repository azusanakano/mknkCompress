mknkYahooCompress 3.0.4 Native
================================

開発・提供: ネコシステム社

ヤフオク出品画像専用のWindowsネイティブJPG圧縮アプリです。
インストール不要・完全オフラインで動作します。

使い方
------
1. mknkYahooCompress.exe を起動します。
2. 画像またはフォルダーを画面へドロップします。
3. 元画像と同じ場所へ「元名_yahoo.jpg」が自動作成されます。

接尾辞の保存
------------
「圧縮後の接尾辞」を変更して「保存」を押すと、次回起動時にも使用されます。
空欄の場合は _yahoo に戻ります。

画面の位置・サイズの記憶
------------------------
画面を移動・サイズ変更するだけで自動保存します。
次回起動時は、前回の位置・サイズ・最大化状態を復元します。
最小化したまま終了した場合は、最小化前の通常表示または最大化で起動します。
保存位置が完全に画面外なら、Windowsが見える位置へ調整します。
保存ボタンを押す操作は不要です。
v3.0.3からの更新はEXEの入れ替えで可能です。接尾辞など既存設定は引き継ぎます。

固定仕様
--------
- JPG固定
- 1枚5,000,000 bytes以下
- 元画像の容量以下（変換後に大きくしない）
- 長辺1200px以下
- 5MBかつ元画像容量内で知覚品質が最も高い候補を採用
- 元画像は上書きしない

対応OS
------
Windows 10 / 11

プライバシー
------------
- 画像や利用情報を外部送信しません。
- 撮影情報・ICC保持は既定でOFFです。
- 設定は %LOCALAPPDATA%\\mknkYahooCompress\\settings.ini に保存します。
