mknkYahooCompress 3.0.4 Native - VALIDATION REPORT
===================================================

Date: 2026-09-10
Provider: ネコシステム社 / Neko System
Target: Windows 10/11, x64/x86/ARM64
Runtime: Win32 + Windows Imaging Component

Changes
-------
- Automatically save and restore normal window position and size.
- Retain maximized state and the normal restore rectangle.
- Reopen a minimized window in its last normal/maximized state.
- Track the last non-minimized WM_SIZE state rather than relying on
  GetWindowPlacement flags to remember maximize-before-minimize.
- Save after move/resize, on normal close, and on session-end notifications.
- Debounce move/size events; protect saved data during initial restoration.
- Validate the checksummed placement record; use defaults for invalid data.
- Use GetWindowPlacement/SetWindowPlacement together to preserve workspace
  coordinates and use Windows' recovery of completely offscreen placement.
- Store the new window section in the existing settings.ini file.

Compatibility and branding review
---------------------------------
- Product remains mknkYahooCompress by ネコシステム社.
- EXE filename, window class, application identity, and settings directory
  retain their v3.0.3 values. No brand migration is introduced.
- Suffix, output directory, metadata and appearance settings remain in place.
- Compression processing is unchanged: JPG-only, <= original size and
  <= 5,000,000 bytes, maximum long edge 1200px.
