# 3.0.4 Yahoo Native

- ウィンドウの位置・サイズ・最大化状態を保存し、次回起動時に復元
- 移動・サイズ変更後、通常終了、Windowsログオフ・終了通知で保存
- 最小化状態で終了した場合は、最小化前の状態へ復元して起動
- 起動・復元中のイベントで前回の記録を上書きしないよう保護
- Win32標準の位置復元APIで、モニターを外した際の完全な画面外配置を補正
- 破損した記録・不正なサイズは初期位置・サイズへフォールバック
- 一時INIを使う位置復元のWindows結合テスト9シナリオを追加
- ソースZIPへ既存の配布ZIPやGit履歴が重複混入しないよう梱包対象を修正

ネコシステム社ブランド、アプリの識別名・設定保存先を継続。
接尾辞保存、元画像容量以下・5MB以下の制約、JPG固定の圧縮処理を継承。
